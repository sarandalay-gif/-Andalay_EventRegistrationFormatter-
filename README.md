# -Andalay_EventRegistrationFormatter-
Description

This Python program collects student information and event details. It formats the student's name, converts the section to uppercase, and displays the event date in a readable format.

Features

Formats the student's full name.

Displays the name in uppercase.

Converts the section to uppercase.

Formats the event title.

Displays the event date with the month name.

Identifies the programming language and features used.

Language Used

Python

String Methods Used

strip() – removes extra spaces at the beginning and end.

title() – capitalizes the first letter of each word.

upper() – converts text to uppercase.

Date/Time Feature Used

datetime.date() creates and validates the event date, while strftime() formats it into a readable date.

How to Run

Open event_registration.py in VS Code.

Run the Python program.

Enter the requested student and event information.

View the formatted registration summary.
